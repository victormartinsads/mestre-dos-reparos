# Mestre dos Reparos — Landing Page Premium

Landing page de alta conversão para a **Mestre dos Reparos**, especializada em soluções, reparos e manutenção residencial de alto padrão no Rio de Janeiro.

## 🚀 Tecnologias

- **HTML5 & CSS3 Moderno** (Design System com variáveis CSS, responsividade fluida, micro-interações)
- **Vídeo em Alta Definição com Streaming** no Hero
- **Node.js** (Servidor HTTP local nativo com suporte a HTTP Range para streaming de vídeo)

## 🎨 Identidade Visual

- **Preto & Carvão Nobre (`#0B0E14` / `#07090D`)**: Elegância arquitetônica e contraste de luxo.
- **Amarelo Ouro (`#FFB800` / `#E5A500`)**: Destaque e alta conversão para chamadas de ação (CTA).
- **Branco Puro (`#FFFFFF`) & Off-White (`#F8F9FA`)**: Leitura confortável e clareza visual.

## 📦 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/victormartinsads/mestre-dos-reparos.git
cd mestre-dos-reparos
```

2. Inicie o servidor local:
```bash
node server.js
```

3. Acesse no navegador:
```
http://localhost:4040
```
